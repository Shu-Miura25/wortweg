# WortWeg v4 — VS Code + スマホで学べるドイツ語単語アプリ

ADAのミニマルなデザインから着想を得た独自のWebアプリです。サーバー契約・Node.js・ビルドは不要です。

## 1. VS Codeで開く（Windows）

1. ZIPを任意のフォルダ（例：`WortWeg`）に解凍します。`index.html` が入っているフォルダが作業フォルダです。
2. VS Codeを開き、**ファイル → フォルダーを開く** からそのフォルダを選びます。
3. 拡張機能（Ctrl+Shift+X）で **Live Server**（Ritwick Dey）をインストールします。
4. `index.html` を開き、右下の **Go Live** を押します。
5. Chromeで `http://127.0.0.1:5500/` が開けば成功。ブラウザで単語学習できます。

> 補足: `index.html` を直接ダブルクリックしても動く構成ですが、スマホ公開時と同じ挙動を試すためLive Serverを推奨します。編集内容は保存（Ctrl+S）後、ブラウザに反映されます。

## 2. どのファイルを編集する？

- `index.html` — 画面の構造、ボタンや見出し
- `style.css` — デザイン、配色、余白、レスポンシブ対応
- `app.js` — 学習モード、正誤判定、暗記済みマークなど
- `data/words.js` — サンプル単語データ。追加・修正はここでも可能
- `manifest.webmanifest` — スマホのホーム画面アイコン/アプリ名の設定
- `sw.js` — オフライン利用の仕組み（Service Worker）
- `.vscode/` — VS Codeの推奨拡張機能と設定

最初にコードを触るなら `style.css` を開いて色や文字のサイズを変更すると、HTML/CSSが理解しやすいです。以前のスタイルの上に新しいStudio Editionのスタイルを上書きしているため、見た目を変更するときは `style.css` の後半「WortWeg / Studio Edition」（約269行目以降）を編集してください。学習モードの仕組みは `app.js` の `filterEligible()` → `start()` → `renderCard()` → `checkAnswer()` の順に確認できます。

### 配色のルール
正解： `#7a1d1a`（赤系） / 不正解： `#1a1d7a`（青系）

## 3. iPhone / Androidで使う（無料のGitHub Pages）

1. GitHubで新しい**公開リポジトリ**（例：`wortweg`）を作成します。
2. このフォルダ内のファイル/フォルダを、**フォルダごとではなく中身を**リポジトリの最上位にアップロードします（`index.html`, `style.css`, `app.js`, `data`, `sw.js` など）。隠しファイル `.nojekyll` や `.vscode` は公開に必須ではありません。
3. GitHubの **Settings → Pages → Build and deployment** で `Deploy from a branch` → `main` → `/(root)` → **Save** を選びます。
4. 表示された `https://GitHubユーザー名.github.io/wortweg/` のようなURLをスマホのSafari/Chromeで開きます。
5. iPhoneはSafariの**共有**→**ホーム画面に追加**（表示される場合は「Webアプリとして開く」を有効にする）。AndroidはChromeの**メニュー**→**ホーム画面に追加**/インストールを使います。
6. オンラインで初回表示すると必要ファイルをキャッシュします。以後はオフラインでも起動できます（ブラウザ/OSの保存容量設定に依存します）。

### VS Codeから変更を公開するには

VS Codeで編集 → 保存 → Gitでコミット・push、またはGitHub上に変更ファイルをアップロードしてください。アップロード後はスマホで開き直すと更新を取得します（古い画面が残るときは再読み込み）。

## 4. 現在の学習機能

- ドイツ語＋日本語、片方を隠す2モード
- 日本語→ドイツ語記述式（名詞の性は der/die/das 三択、名詞の綴りは冠詞なし）
- 名詞の性だけを答える三択
- CEFR A1/A2/B1・品詞・指定語数でランダム出題
- 暗記済みマークと出題除外、単語検索
- 自分の単語の手動追加／CSV取り込み／バックアップ
- ドイツ語特殊文字の入力ボタンとヘルプ

内蔵427語はサンプルです。Goethe-Institutの公式語彙リスト全件を含むものではなく、レベル分けも参考用です。

## 5. 学習データとプライバシー

- 暗記済み情報と追加語彙はブラウザの **localStorage** に保存します。
- **PCとスマホの記録は自動同期しません。** PCで「データ管理 → バックアップ」を保存し、スマホの「バックアップ復元」で引き継げます。
- 同じ端末でもサイトURL・ブラウザが変わると記録は別扱いになります。
- GitHubに公開すると **アプリのソースコードと内蔵語彙は公開** されます。個人情報やパスワードは含めないでください。
- サービスワーカーを変更した場合は `sw.js` の `CACHE` 名を v5 のように更新すると再取得されます。

## トラブルシュート

- 真っ白なページ：Chromeの開発者ツール（F12）→Consoleのエラーを確認。`app.js` と `data/words.js` が同じ構成で存在するか確認。
- VS Codeに「Go Live」がない：Live Server拡張が有効かを確認。
- GitHub Pagesが404：`index.html` がリポジトリのルートにあるか、Pagesのブランチ設定を確認。
- スマホで古い画面：Safari/Chromeで再読み込み。必要ならブラウザのサイトデータ・キャッシュを見直す（学習記録が消える場合があるため先にバックアップ）。
