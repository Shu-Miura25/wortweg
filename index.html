HELP & KEYBOARD GUIDE

ヘルプ・ドイツ語の入力方法

Windowsパソコンやスマートフォンでも、ドイツ語の特殊文字を簡単に入力できます。

一番簡単な方法

記述問題の入力欄の下にある ä / ö / ü / ß ボタンを押すと、その文字がカーソル位置に入ります。アプリ内ならキーボードの設定は不要です。

ä　ö　ü　ß　Ä　Ö　Ü
01 · WINDOWS

Windowsのキーボード

方法A：アプリの文字ボタン を使うのがおすすめです。ノートパソコンでも使えます。

方法B：ドイツ語キーボードを追加

  1. 「設定」→「時刻と言語」→「言語と地域」を開く
  2. 「言語の追加」から「ドイツ語」を追加する（必要に応じてキーボードレイアウトも設定）
  3. Windows + Space で入力言語を切り替える

ドイツ語配列にすると Y と Z など一部のキーの配置が変わります。日本語配列の印字とキー位置が一致しないことがあります。

02 · WINDOWS

Altコードで直接入力

Alt を押しながら テンキーで数字を入力 し、Altを離します。

äAlt + 0228öAlt + 0246üAlt + 0252ßAlt + 0223ÄAlt + 0196ÖAlt + 0214ÜAlt + 0220

数字はキーボード上段ではなくテンキーを使用します。テンキーがないノートPCでは、アプリ内の文字ボタンが確実です。

03 · IPHONE / ANDROID

スマホでの入力

キーボードの a / o / u / s を長押しして、表示された候補から ä / ö / ü / ß を選びます。

iPhoneでは「設定」→「一般」→「キーボード」→「キーボード」から「ドイツ語」を追加することもできます。

スマホでも記述問題に表示される文字ボタンをタップするだけで入力できます。

04 · LEARNING MODES

学習モードについて

記述式： 名詞は der / die / das を三択で選び、入力欄には Hund のように冠詞なしで綴りを入力します。名詞の最初の文字は自動で大文字になります。

性だけモード： 名詞の綴りと日本語訳を見て、der / die / das のいずれかを選びます。レベル別のランダム練習・暗記済み除外にも対応します。

名詞の性を練習するには、単語帳に冠詞付き（例：die Erfahrung）で登録してください。採点時の綴りの大文字・小文字は区別しません。

単語データ・バックアップ

手動追加やCSVの一括取り込みに対応しています。

新しい単語を追加

名詞は der / die / das を含めて登録するのがおすすめです。

CSV・TSVから一括取り込み

列名が de, ja, level, pos のUTF-8ファイルに対応。日本語列名も使用できます。

例：der Hund,犬,A1,noun
品詞：noun / verb / adj / adv / prep / conj / expr
同じレベル・品詞・ドイツ語の重複は取り込みません。

学習データのバックアップ

追加した単語と暗記済みの情報をJSONファイルとして保存・復元できます。

別端末との自動同期はありません。iPhoneやPCを変える場合はバックアップを使ってください。

データの管理

暗記済みマークのリセット、追加した単語の削除ができます。
